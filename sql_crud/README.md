# Data Modeling and Persistence

This repository contains projects and exercises from the **Holberton School** curriculum focused on data modeling, databases, SQL, and data persistence.

## Repository Contents

The repository contains projects covering different concepts related to data storage and manipulation, including:

* SQL and relational databases
* Data modeling
* Database operations
* Data persistence

## Projects

### SQL CRUD

Directory:

```text
sql_crud/
```

This project introduces the fundamentals of **SQL** and the **relational model** using **SQLite**.

It covers:

* Tables, rows, and columns
* `SELECT`
* `INSERT`
* `UPDATE`
* `DELETE`
* `WHERE`
* `ORDER BY`
* `LIMIT`
* Aggregate functions
* `GROUP BY`

## Technologies

* SQL
* SQLite
* Bash / Linux command line
